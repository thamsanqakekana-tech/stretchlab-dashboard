## The Responsibility Model (Apply Everywhere)

This is the foundation for every narrative decision on this page:

**Execo owns everything before the studio door:**
Getting the call, the conversation, the booking, the confirmation follow-up, protecting the pipeline appointment from falling away. Every cancellation is either a lead commitment failure (Execo's problem to solve) or a studio-side admin issue (shared pattern to surface together).

**StretchLab owns everything after the studio door:**
The intro session experience, converting the attended lead into a paying member. The real ROI of this partnership is not the $69 intro session — it is the monthly membership LTV that Execo's outreach unlocks. Every attended session is a warm, confirmed prospect StretchLab received without having to acquire them through standard marketing. The dashboard should make StretchLab feel the weight and the opportunity of that.

Never direct StretchLab to do anything related to calling, follow-up, or booking. Never frame cancellations as StretchLab's problem to fix. Frame attended sessions as StretchLab's opportunity to convert.

## Change 2 — Pipeline Section: Make the 8 Appointments Feel Alive

### What to build

A new section between `StudioStrip` and `NarrativeCard`. This section surfaces every upcoming appointment as a named card with risk context. It is the most forward-looking, action-driving section on the page.

### Data source

`phiwe_pipeline.csv` columns: `first_name`, `last_name`, `booking_location`, `booking_date`, `days_until`, `risk_level`, `total_calls_made`

### Component: `PipelineSection`

```javascript
function PipelineSection({ pipeline = [], isClientView = false }) {
  if (!pipeline.length) return null

  // Sort: soonest first, then by risk (High before Medium before Low)
  const riskOrder = { High: 0, Medium: 1, Low: 2 }
  const sorted = [...pipeline].sort((a, b) => {
    const dateA = new Date(a.booking_date), dateB = new Date(b.booking_date)
    if (dateA - dateB !== 0) return dateA - dateB
    return (riskOrder[a.risk_level] ?? 3) - (riskOrder[b.risk_level] ?? 3)
  })

  const highRisk   = pipeline.filter(r => r.risk_level === 'High').length
  const totalCount = pipeline.length

  // Risk colour and border
  const riskColor = (level) =>
    level === 'High'   ? '#E24B4A' :
    level === 'Medium' ? '#EF9F27' : '#1D9E75'

  // Context line per appointment — computed from pipeline data, never hardcoded
  const appointmentContext = (r) => {
    const calls = Number(r.total_calls_made || 0)
    const days  = Number(r.days_until || 0)
    const name  = r.first_name
    const studio = String(r.booking_location || '').replace('StretchLab ', '')

    if (r.risk_level === 'High' && calls <= 1)
      return `${name} has had ${calls === 0 ? 'no' : '1'} call — confirmation follow-up is the priority this week`
    if (r.risk_level === 'High' && days <= 5)
      return `${days === 0 ? 'Today' : `${days} day${days === 1 ? '' : 's'} away`} — final confirmation window is now`
    if (r.risk_level === 'Medium')
      return `${calls} call${calls !== 1 ? 's' : ''} made — follow-up on track`
    if (r.risk_level === 'Low')
      return `${calls} call${calls !== 1 ? 's' : ''} made — well-protected`
    return `${calls} call${calls !== 1 ? 's' : ''} made`
  }

  return (
    <Card style={{ marginBottom: '24px' }}>
      {/* Header */}
      <div style={{ display: 'flex', alignItems: 'baseline', justifyContent: 'space-between', marginBottom: '14px' }}>
        <p style={{ fontSize: '11px', fontWeight: 700, color: 'var(--muted)', textTransform: 'uppercase', letterSpacing: '0.08em', margin: 0 }}>
          Active Pipeline — {totalCount} upcoming session{totalCount !== 1 ? 's' : ''}
        </p>
        {highRisk > 0 && (
          <span style={{ fontSize: '11px', color: '#E24B4A', fontWeight: 600 }}>
            {highRisk} high-risk · confirmation follow-up priority
          </span>
        )}
      </div>

      {/* Appointment cards */}
      <div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
        {sorted.map((r, i) => {
          const name     = [r.first_name, r.last_name].filter(Boolean).join(' ')
          const studio   = String(r.booking_location || '').replace('StretchLab ', '')
          const date     = r.booking_date
            ? new Date(r.booking_date).toLocaleDateString('en-US', { month: 'short', day: 'numeric' })
            : '—'
          const days     = Number(r.days_until || 0)
          const color    = riskColor(r.risk_level)
          const context  = appointmentContext(r)

          return (
            <div key={i} style={{
              display: 'flex', alignItems: 'center', gap: '12px',
              padding: '10px 14px',
              background: 'var(--bg)',
              border: `1px solid var(--border)`,
              borderLeft: `3px solid ${color}`,
              borderRadius: '6px',
            }}>
              {/* Risk badge */}
              <span style={{
                fontSize: '9px', fontWeight: 700, padding: '2px 7px',
                borderRadius: '4px', textTransform: 'uppercase', letterSpacing: '0.06em',
                background: `${color}18`, color, flexShrink: 0,
              }}>
                {r.risk_level}
              </span>

              {/* Name + studio */}
              <div style={{ flex: 1, minWidth: 0 }}>
                <p style={{ fontSize: '13px', fontWeight: 600, color: 'var(--text)', margin: 0, whiteSpace: 'nowrap', overflow: 'hidden', textOverflow: 'ellipsis' }}>
                  {name}
                </p>
                <p style={{ fontSize: '11px', color: 'var(--muted)', margin: 0 }}>
                  {studio}
                </p>
              </div>

              {/* Session date */}
              <div style={{ textAlign: 'right', flexShrink: 0 }}>
                <p style={{ fontSize: '12px', fontWeight: 700, color: 'var(--text)', fontFamily: 'JetBrains Mono, monospace', margin: 0 }}>
                  {date}
                </p>
                <p style={{ fontSize: '10px', color: 'var(--muted)', margin: 0 }}>
                  {days === 0 ? 'today' : days === 1 ? 'tomorrow' : `${days}d away`}
                </p>
              </div>

              {/* Context line — Execo action context, not client instruction */}
              <p style={{ fontSize: '11px', color: 'var(--muted)', fontStyle: 'italic', margin: 0, flexShrink: 0, maxWidth: '280px', textAlign: 'right' }}>
                {context}
              </p>
            </div>
          )
        })}
      </div>

      {/* Partnership frame — StretchLab's opportunity */}
      <p style={{ fontSize: '12px', color: 'var(--muted)', margin: '12px 0 0', lineHeight: 1.6, borderTop: '1px solid var(--border)', paddingTop: '10px' }}>
        Each of these {totalCount} sessions is a dormant lead Execo has confirmed back through the studio door.
        {' '}StretchLab's opportunity is to convert every attended session into an active membership — that is where the real return on this campaign is built.
      </p>
    </Card>
  )
}
```

  try {
    const res = await fetch('/outputs/latest.json')
    if (!res.ok) throw new Error('No latest.json')
    const { folder } = await res.json()
    return `/outputs/${folder}`
